API v1

Bank Statement Parser API

Programmatically parse Indian bank statements (PDF, DOCX, TXT) into structured JSON data. Supports 10+ banks with AI fallback.

🔑 Authentication

All API endpoints (except /api/v1/status and this docs page) require an API key.

Pass your key via the X-API-Key header:

curl -X POST {{ base_url }}/api/v1/parse \
  -H "X-API-Key: your-api-key" \
  -F "file=@statement.pdf"

Alternatively, use the api_key query parameter:

curl -X POST "{{ base_url }}/api/v1/parse?api_key=your-api-key" \
  -F "file=@statement.pdf"
Need an API key? Contact wecare@tohundguide.com to request access.

📡 Endpoints

POST /api/v1/parse

Upload and parse a bank statement. Returns structured transaction data.

Request (multipart/form-data)

FieldTypeRequiredDescription
fileFileNo*Bank statement (PDF, DOCX, TXT, CSV). Max 200MB.
urlStringNo*URL to download the file from. Supports Google Drive, Dropbox, OneDrive, and direct links. File must be publicly shared.
bankStringNoBank code (e.g. jkbank, hdfc). Default: auto (auto-detect).
passwordStringNoPDF password, if the file is password-protected.
formatStringNojson (default) — full transaction data. excel — includes download URL for .xlsx file.
* Either file or url must be provided. If both are given, url takes priority.

Example: File Upload

curl -X POST {{ base_url }}/api/v1/parse \
  -H "X-API-Key: your-api-key" \
  -F "file=@hdfc_april_2025.pdf" \
  -F "bank=auto"

Example: Google Drive URL

curl -X POST {{ base_url }}/api/v1/parse \
  -H "X-API-Key: your-api-key" \
  -F "url=https://drive.google.com/file/d/FILE_ID/view?usp=sharing" \
  -F "bank=auto"

GET /api/v1/status

Check system status, supported banks, and available features. No authentication required.

Example

curl {{ base_url }}/api/v1/status

Response

{
  "version": "2.1",
  "banks": [
    { "code": "jkbank", "name": "JK Bank" },
    { "code": "hdfc", "name": "HDFC Bank" }
    // ...
  ],
  "features": {
    "excel_export": true,
    "ai_fallback": true,
    "ocr_scanned_pdfs": true
  }
}
GET /api/v1/download/<filename>

Download a generated Excel or CSV file. Only available when format=excel is used in the parse request. Requires authentication.

⚠️ Files expire after 1 hour. Download immediately after parsing.
